# 地域素材表規格 — Region Asset Sheet Spec

> 給「產新地域圖」用的模板。照這份產圖，程式就能**統一切圖、統一運作**，不必每張重新校準。
> 反推自現有三地域（草原 / 王國 / 海城）+ 實際 `ParallaxBackground`/`WorldScroll` 常數。

---

## 0. 一句話
一張圖 = 一個地域（biome）。內含**由遠到近 4 條全寬背景層 + 一列可拆道具**（＋選配角色列）。程式把 4 層做**視差捲動**、把道具**散落沿路**、地域交界**淡入淡出**。

## 1. 畫布 Canvas
- **尺寸固定 1536 × 1024 px**、PNG。
- **像素風**，像素尺度（每「像素塊」的粗細）要與現有地域一致——這樣三地域轉場 crossfade 時不會一邊細一邊粗。
- 色調：溫暖、中古奇幻、吉卜力感、**無黑暗/威脅**（世界觀鐵律）。

## 2. 版面結構（由上而下）
| 區 | 名稱 | 內容範例 | 螢幕視差係數* | 說明 |
|---|---|---|---|---|
| 1 | **遠景 Far** | 地平線：遠山、天際城、海岸 | **0.15**（最慢） | 最低對比、霧化、退遠 |
| 2 | **中景 Mid** | 中距量體：城牆塔樓、森林、港埠 | **0.45** | 中等細節 |
| 3 | **前景 Fore** | 近景帶：旗幟石牆、樹列、碼頭沿 | **0.65** | 高細節（可選；有些地域可省略此層） |
| 4 | **地面平台 Ground** | 角色腳踩的地帶（草土/石板/碼頭石） | **1.00**（最快） | **頂緣＝角色腳線** |
| 5 | **道具列 Props row** | 燈柱/旗幟/木箱/木桶/長椅/樹/花/貨車… | — | 一個個獨立小物，供沿路散落 |
| 6 | （選）**角色列 NPC row** | 該地域的居民（士兵/商人/…）4 向 | — | 只有想放「城中行人」才需要 |

*視差係數是**程式固定的**（你不用管），列出只為讓你理解：**越遠畫越淡、越近畫越實**，捲動時才有景深。

## 3. 硬性規則（違反 → 程式吃不進去 / 畫面會破）
1. **每條背景層都要「全寬 + 水平無縫平鋪」**：左緣要能接右緣（把它左右重複貼不出現接縫）。**這是無限捲動的命脈**。
2. **四層由上而下順序固定**：遠 → 中 → 前 → 地面。中間留一點分隔空隙好切。
3. **地面層是關鍵基準**：
   - 它的**頂緣＝角色站立的腳線**。
   - **地面層在畫布中的高度佔比要跟現有地域接近**（程式會把地面縮到螢幕 40pt 高、其餘層用**同一縮放比**跟著縮 → 地面佔比＝整個地域的尺度基準；佔比差太多，整個地域會忽大忽小）。
4. **道具列**：每個道具**獨立、不重疊、平均分佈**，放在**單一純色（好去背）或透明**底上。道具是「可拆件」，程式會單獨摳出來沿路擺。
5. **像素尺度 + 色盤**與現有地域一致（轉場才不突兀）。
6. **背景層裡不要畫角色**（主角/旅伴是另外的；地域居民請放選配的「角色列」）。
7. **世界觀**：溫暖、平和、無黑暗勢力、無威脅感、無壓迫。

## 4. 深度感（畫圖時的口訣）
遠景：**低對比、去飽和、霧化、少細節**。往前逐層：**對比↑、飽和↑、細節↑**。地面/前景最清晰。（大氣透視 = 景深的來源。）

## 5. 建議固定座標（1536×1024，供「零手動校準」）
> 只要你把各層放進這些帶狀範圍、標籤文字放最左邊 90px 邊界內，切圖器就能用**固定座標**一次吃進所有符合的圖（我會把切圖器對齊這份模板）。座標可微調、非像素級精準也沒關係，程式有容差。

- **左側標籤邊界**：x 0–90（遠景/中景/前景/地面平台 字放這，會被裁掉）
- **內容區**：x 96–1470（全寬景物畫這；務必左右可接）
- **各層 Y 帶**（由上而下）：
  - 遠景 Far：y 30 – 250
  - 中景 Mid：y 280 – 500
  - 前景 Fore：y 530 – 740
  - 地面平台 Ground：y 760 – 875（可行走地帶）
  - 道具列 Props：y 895 – 1015（一排獨立小物）
- 帶與帶之間留 ~15–30px 空隙（純色）好自動分割。

## 6. （選）角色列 NPC row
想讓地域「有人」才需要。格式同主角素材：
- N 種居民 × **4 向（向右 / 向左 / 向前 / 前後）**，每格同尺寸、對齊網格。
- 角色**身高與主角相近**（約佔地面帶高度）；一格一個 pose，站姿即可。
- 可放在道具列右側或另起一列，標「角色」。

## 7. 交付
- 一個地域一張 PNG、**1536×1024**、命名 `<地域英文>.png`（如 `desert.png`、`snow_village.png`、`forest.png`）。
- 標籤（遠景/中景…）留最左邊界即可，我會裁掉。

## 8. 兩份可直接用的提示（ChatGPT 自由發想版 · 不必填空）
> 場景、角色**分開兩張圖、兩段提示**。內容讓 ChatGPT 自己發想，格式由提示鎖死。
> 產完把圖丟進 `design/`：場景 → `design/<地域>.png`、角色 → `design/<地域>_characters.png`。

### 8A. 場景素材表（Scene）
```
你是像素美術與關卡設計師。請你自由發想一個全新的中古奇幻「地域」（biome）——
主題由你決定，但要溫暖、平和、無黑暗無威脅，且與「草原田園、城堡王城、港口海城」不同
（例如沙漠綠洲、雪國村莊、幽靜森林、秋日山谷、河畔小鎮、高原、峽谷、花田…挑一個有特色的）。
然後把它畫成一張 2D 橫向捲軸遊戲的「地域素材表」。

技術規格（務必嚴格遵守，程式要靠這個切圖）：
- 尺寸 1536×1024、PNG、像素風、像素尺度中等偏粗、色盤明亮溫暖。
- 由上而下 4 條「全寬、且左右可無縫平鋪（左緣要能接右緣，重複貼不出現接縫）」的水平背景帶：
  1. 遠景 Far：遠地平線，低對比、霧化、退遠。
  2. 中景 Mid：中距量體，中等細節。
  3. 前景 Fore：近景帶，高對比、細節多。
  4. 地面平台 Ground：可行走的地面帶（地表材質配合你的主題），其頂緣是角色站立線。
- 最下面一排「彼此分開、不重疊」的獨立道具（配合主題自己發想 8~12 個，如樹/燈柱/木桶/木箱/花/攤子/石件…），
  全部放在單一深色純底上、平均排列。
- 背景層裡「不要畫任何人物角色」。
- 由遠到近：對比與飽和度遞增（大氣透視＝景深）。整體色調可與其他地域無縫拼接。
- 每條帶最左邊標小標籤：遠景／中景／前景／地面平台。

請直接產出這張圖。
```

### 8B. 角色素材表（Character）
```
你是像素美術角色設計師。請你自由發想 3~4 個中古奇幻世界的居民/旅人角色——
是誰由你決定，但要溫暖、親切、無威脅（例如商人、農夫、孩童、老者、樂手、麵包師、漁夫、
旅人…挑一組有變化又討喜的組合）。然後畫成一張「角色素材表」。

技術規格（務必嚴格遵守，程式要靠這個切圖）：
- PNG、像素風，像素尺度與色盤和地域素材表一致（能擺進同一個世界）。
- 每個角色畫 4 個方向：向右、向左、向前（面向鏡頭）、背面；排成整齊網格、每格同尺寸並對齊。
- 所有角色身高一致、彼此相近，站姿即可（一格一個 pose），頭身比適合像素小人。
- 全部放在單一深色純底上（方便去背摳出）。
- 溫暖、無盔甲壓迫感、無武器威脅、無黑暗。
- 每個角色可在上方標小標籤（例如「商人」「孩童」）。

請直接產出這張圖。
```
> 場景與角色是**兩張不同的圖**：場景給背景/道具，角色給該地域的居民 NPC。兩者都丟給我，我切圖 + 接進世界（四季/晝夜/相遇卡/轉場自動套上）。

## 9. 程式怎麼用這些元素（為何規則重要）
- 4 條背景層 → 各以自己的 `layerFactor`（0.15/0.45/0.65/1.0）**無縫平鋪捲動** → 景深 + 無限延伸。
- 地面頂緣 → 角色腳線（固定螢幕高度 40pt，故地面佔比＝尺度基準）。
- 道具 → 單獨摳出、沿里程**確定性散落**（`PropScatter`）。
- 角色列 → 地域居民 NPC（`KingdomNpcScatter` 範式，站崗/散步、隨世界捲動）。
- 地域交界 → 相鄰地域背景 **crossfade 轉場**（`Region.blend`）。
- 四季 tint / 晝夜 / 天氣 / 相遇卡 → 疊在任何地域之上，自動運作，你不用出。

---
*對齊實作：`ParallaxBackground`（groundDisplayHeight=40、propDisplayHeight=34、layerFactor 遠0.15/中0.45/前0.65/地面1.0）、`WorldScroll.panoramaTileXs`（無縫平鋪）、`Region`（地域序列+blend）、`slice_assets.py`（切圖）。*
