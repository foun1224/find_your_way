## 0. 一條總線（先講結論）

無邊世界的心理學紅利與風險，是同一枚硬幣的兩面：

- **紅利（為什麼值得做）**：`02` §6 ART 的核心是「**永遠有不費力可看的新東西 → 注意力持續恢復**」。一個永遠變化、永遠有新風景的世界，是 soft fascination 的**極大化**；`02` §5「旅程即人生」的隱喻，在**無終點**時才真正成立（人生沒有通關）。
- **風險（最須守住的線）**：無邊內容最容易滑向的三個深淵是 **grind（刷）、collect（收集強迫）、FOMO（錯過焦慮）**。一旦「無邊」被實作成「有很多東西要蒐集/要走完/怕錯過」，它就從**療癒**變成**壓力**，直接踩穿六條紅線。

> **本文件的設計靈魂一句話**：**無終點是「路一直都在」的安心，不是「永遠做不完」的壓力。** 世界永遠展開，但使用者永遠「剛剛好走到這裡就很好」——沒有進度條的盡頭在催、沒有未探索區域在焦慮、沒有限時在逼。走多遠都完整，停在哪裡都完整。

這條總線貫穿以下所有設計決定。凡有機制傾向「讓人怕錯過、想蒐集、要走完」，即與願望相悖，一律否決（§6 逐條把關）。

## 1. 無邊世界的結構模型：以地域 (Region / Biome) 為單位串接里程軸

### 1.1 核心模型：里程軸上的「地域帶 (Region Band)」

沿用專案已驗證的核心範式——**一切掛在里程軸 (distance axis) 上**（`09` §2.1；ADR-009 世界捲動由 `distance` 驅動）。無邊世界只是把這條軸**無限延伸**，並在其上**分段**成一個個**地域帶 (Region Band)**：

```
distance →  0 ─────────────────────────────────────────────────────→ ∞
           │ 草原/村莊  │  森林   │  丘陵  │  濕地 │ 海岸 │ 沙漠 │ 高山 │ …永遠展開
           │ (Region 0) │ Region1 │  ...
           └ 既有 §10 內容 ┘   ← 新地域為長期擴充方向
```

- **一個 Region Band = 里程軸上的一段區間**，長度為一個常數 `regionLength`（相對 P1 速率，如「數個旅程日」一帶，待手感定，見 §7）。
- **每個地域帶承載一整套環境語言**：
  | 面向 | 內容 | 承載層 |
  |---|---|---|
  | **地形 terrain** | 草原 / 林地 / 丘陵 / 濕地 / 海岸 / 沙丘 / 山脊 … | parallax 各層地貌素材（`03` §2.4） |
  | **色調 palette** | 該地域的主色偏移（綠→黃綠→赭→藍綠→砂金→冷白） | 全域 tint + 素材（`03` §1.2/§1.4） |
  | **氣候 climate** | 濕/乾、暖/涼、光線質地（見 §3） | tint 色溫 + 天氣機率權重 |
  | **動植物 flora/fauna** | 該地域會出現的花、樹、鳥獸（見 §5） | 氛圍微事件 B 類 + 里程相遇卡 A 類 |
  | **聚落/文化 settlement/culture** | 可能有的村鎮、人文風味（見 §4） | 聚落地標 + 文化相遇卡 |

- **「前進 = 走進新地域」**：使用者不需要做任何事，`distance` 隨時間累加（在線/離線同速，ADR-005），走著走著地貌就從草原漸變成林邊、從林邊漸變成丘陵——**「遇到新風景」= 「走到了那裡」**（延續 `09` §2.1「遇到事件 = 走到了那裡」的哲學，不是「擲骰中了」）。

### 1.2 地域如何「轉場」：漸變重疊帶 (Blend Zone)，不是硬切

無邊世界最怕「一格草原、下一格突然沙漠」的生硬跳接（也違反 `03` §3.4「無突兀、分鐘級平滑漸變」）。設計上每兩個地域帶之間插入一段**重疊過渡帶 (Blend Zone)**：

- **色調 crossfade**：進入 Blend Zone 後，全域 tint 從前一地域色偏，**分鐘級 / 里程級平滑漸變**到下一地域色偏（技術上零成本，只是 tint 插值，複用 `03` §1.4 晝夜漸變的同一套機制）。
- **地貌交融**：近景圖磚 (L3) 與中景 (L2) 在過渡帶混用兩地域素材（草漸疏、樹漸多；樹漸退、丘陵漸起），像真實地理的生態交界 (ecotone)。
- **敘事留白一句**：過渡可選擇性記一筆極淡的日誌（「草原慢慢矮了下去，遠處開始有樹的輪廓。」），語氣同 `14` §1.3 母帶——**是「風景換了」，不是「你解鎖了新區域」**。

> **關鍵**：轉場是**環境自己在變**，不是**系統向使用者宣告進度**。永遠沒有「新區域已解鎖！」的彈窗、亮點、成就（那是遊戲語言，踩 §6）。

### 1.3 如何「無限延伸且不重複到膩」：地域類型 (Region Type) 的確定性序列

無邊 ≠ 手工鋪無限長的地圖（不可能，也是美術災難，見 §7）。做法是**少量 authored 地域類型 + 確定性序列生成**：

- **authored 一組地域類型 `RegionType`**（如：草原 / 疏林 / 密林 / 丘陵 / 濕地 / 湖岸 / 海岸 / 河谷 / 高原 / 雪山 / 花田 / 竹林 …，Phase 逐步擴充）。每個類型是一組**建構塊**（地貌素材集 + 色偏 + 氣候權重 + 動植物/文化標籤池）。
- **地域序列 = 里程的確定性純函式**（**絕不以牆鐘擲骰**，守 `09` §2.1 禁止清單第一條）：

  ```
  bandIndex   = floor(distance / regionLength)              // 里程分帶，確定性
  regionType(n) = sequenceRule(worldSeed, n, regionType(n-1))
  ```

  - `worldSeed` 為**存檔內固定常數**（存檔建立時寫入一次、永不變；或直接編譯常數），同 `09` §2.3。
  - `sequenceRule` 是一個**帶約束的確定性挑選**：以 `hash(worldSeed, n)` 為 seed，從 `RegionType` 池中挑選，但施加**連貫性約束**——
    - **不緊鄰重複**（剛走過森林，下一帶不會又是森林）；
    - **氣候/地理相鄰性**（沙漠不會緊接雪山；草原→疏林→密林這類自然梯度優先），用一張小的「地域相鄰權重表」authored 定；
    - **季節連貫**（見 §3，季節是另一條慢軸，與地域交織）。
- **為什麼不會膩**：真正的變化感來自**組合爆炸**而非**素材數量**——
  ```
  可感知的「一段路的樣子」 = RegionType × Season × 時段(晝夜) × 天氣 × 當帶抽到的動植物/文化相遇卡
  ```
  即使 `RegionType` 只有十來種，乘上四季、晝夜、天氣、與每帶不同的相遇卡組合，使用者在**很長的旅程裡都不會遇到「一模一樣的一段路」**。這正是 `09` §2.2「authored 建構塊 + 程序化組合」在**地域尺度**的放大。
- **確定性的紅線保證**：因為序列與內容都是 `distance`（里程）的純函式，**同一段路無論何時結算（在線逐次 / 離線一次）都完全相同**（延續 `09` §2.3/§2.4 迴歸鎖）。使用者無法透過「多開幾次」改變世界——**唯一的變數是「走多遠」，而走多遠只由時間決定**。這從根本上排除了變動比率增強（`02` §7）。

> **與 `14` 石門/雪山的關係**：`14` 已將石門/雪山**降格為「途中眾多驚奇之一」**。在本模型裡，它們是**某一種 authored `RegionType`（如「雪山隘口」）裡的一個 authored 地標**——旅人某天會走到某片雪山、看見一道石門，那是美麗的一帶風景，然後繼續往前，前方還有海、還有花田、還有下一片天光。石門不再是終點，是旅途中一次溫柔的驚奇。

## 2. authored vs 程序化 的變化策略（本文件最關鍵處）

### 2.1 原則：authored 建構塊 + 確定性程序化組合

無邊內容**不可能全 authored**（會是無底洞的美術/文案成本），也**不該全程序化**（會失去 `14` 的語氣分寸與留白，滑向冰冷的隨機拼貼）。採**兩者分工**：

| 層級 | 由誰生成 | 內容 | 成本 | 紅線考量 |
|---|---|---|---|---|
| **建構塊 (blocks)** | **Authored**（Fable 把關語氣） | 地域類型、季節、文化風味、動植物/食物/人文**相遇卡**（一句留白日誌 + 標籤） | 一次性、可分階段擴充 | 語氣留白（`02` §5）、零功利（ADR-006） |
| **組合 (composition)** | **程序化（確定性）** | 「哪一帶是什麼地域 / 是什麼季節 / 抽到哪些相遇卡」由**里程/seed 的純函式**決定 | 近乎零（純邏輯） | **絕不牆鐘擲骰**（`09` §2.1）；同一段路恆定 |

### 2.2 相遇卡 (Encounter Card)：無邊內容的最小 authored 單位

把 `09` §10 既有的「里程事件」概念**一般化**為**相遇卡 (Encounter Card)**——一張卡 = 一次旅途中的溫柔遭遇。每張卡是一個**極輕量的 authored 資料**：

```
EncounterCard {
  id
  category:   風景 | 動物 | 植物 | 食物 | 人文 | 休息 | 小相遇   // 純情感/敘事分類
  tags:       [地域類型…, 季節…]          // 決定「這張卡適合在哪出現」
  journalText: 一句留白日誌（14 語氣母帶）  // 例：「一隻鹿在林間抬頭看了看，又低頭吃草。」
  // 無任何功利欄位：不給資源、不加速、不解鎖（ADR-006 嚴格零功利）
}
```

- **A 類 = 里程相遇卡（持久）**：掛里程軸、入 `eventsEncountered`、入日誌、離線可補算——**走 `09` §2.2 A 類確定性範式**。哪一帶抽到哪些卡，由 `hash(worldSeed, bandIndex, slot)` 從**符合當帶 `tags`（地域×季節）的卡池**中確定性挑選。
- **B 類 = 氛圍微相遇（不持久）**：一隻鳥飛過、一片花在風裡搖——純 render 層裝飾，不入狀態、不記錄、錯過毫無損失（`09` §2.2 B 類）。這一層**可以**在線隨機挑動畫，因為它從不被結算、從不被回顧。

> **這個設計的威力**：新增內容 = **多寫幾張 authored 相遇卡（純文字 + 標籤）**，程序化組合層完全不用改。Fable（或使用者用 ChatGPT）可以持續地、低成本地往卡池裡加卡，世界就越來越豐富——**內容擴充與工程解耦**。

### 2.3 「變化感」與「不 grindy / 錯過無損 / 無 FOMO」如何兼得

這是無邊世界最微妙的平衡。關鍵在於**變化的來源是「走過的里程」，不是「使用者的操作或查看」**：

| 想要的 | 怎麼達成 | 為何不踩紅線 |
|---|---|---|
| **變化感（永遠新鮮）** | 組合爆炸（§1.3）+ 持續擴充的相遇卡池（§2.2） | 變化來自「走到新地方」，是時間的自然結果，不是刷出來的 |
| **不 grindy（不刷）** | 沒有任何東西需要「重複做才能拿」——相遇卡只給情感/敘事，零功利（ADR-006） | 沒有可刷的目標 → 無從 grind |
| **錯過無損** | 相遇掛里程軸；離線期間的相遇**完整補算入日誌**（`09` §2.4）；被 12h cap 截斷的里程「還沒走到」而非「錯過」（`09` §2.4 `wasCapped` 語意） | 延續已驗證的「不是錯過，是還沒走到」 |
| **無 FOMO** | 沒有限時卡、沒有「稀有卡」、沒有「這帶不看就沒了」——同一帶你何時走到都是同一批卡 | 一切「回來還在 / 回來也遇得到」（紅線二） |

> **一句話判準（承 `09` §2.1）**：問「這個變化，是為了讓旅程更值得偶爾一看，還是為了讓人更常來看 / 更怕錯過 / 更想蒐集？」——只有前者可進實作。

## 3. 季節 (Season) 與氣候 (Climate)

### 3.1 氣候 vs 季節：兩個不同的東西，分開處理

- **氣候 (Climate) = 地域的內稟屬性**。沙漠本來就乾熱、海岸本來就濕潤、雪山本來就冷冽——氣候**綁地域類型**，跟著 `RegionType` 走（見 §1.1 表）。它主要透過**天氣機率權重**（沙漠少雨、海岸多雲）與**光線質地**（tint 色溫）表現。
- **季節 (Season) = 疊加在地域之上的慢週期**。同一片森林，春夏秋冬**不同**——這是使用者願望裡明確要的「同一片風景也會變化」。

### 3.2 季節怎麼推進？—— 建議「綁里程為主，真實日期為可選氛圍層」

`14`/`09` 的紅線核心是**持久內容不得以牆鐘擲骰**（`09` §2.1）。據此給出分層建議：

| 方案 | 季節怎麼定 | 優點 | 風險 | Opus 傾向 |
|---|---|---|---|---|
| **A. 綁里程（建議主軸）** | 季節是里程的慢週期純函式：`season = f(distance)`，每 `seasonLength` 里程走完一輪春→夏→秋→冬（`seasonLength` 遠大於 `regionLength`，故一個地域內就能經歷季節變化） | **完全確定性**、離線可重現、與「旅程即人生」隱喻一致（季節是你「走到人生的哪個時節」，不是日曆）；持久相遇卡可安全帶季節標籤 | 與現實季節脫節（冬天的現實裡遊戲可能是夏天） | **主軸採此**——這是唯一能讓「季節相遇卡」安全持久化、離線可重現的方案 |
| **B. 綁真實日期** | 季節 = 現實當前月份 | 與使用者現實同步、有「陪你過四季」的親密感 | 若拿來決定**持久相遇卡**就等於牆鐘擲骰（踩 `09` §2.1）；且使用者玩很久才會遇到的地域，其季節取決於「你哪天走到」→ 難重現 | **不作為持久內容的 seed** |
| **C. 混合（建議實際採用）** | **持久層綁里程（A）**；**純氛圍 tint 層可選綁真實日期** | 兼得：日誌/相遇卡確定性可重現（A），而「今天打開時的整體色溫」可微微呼應現實季節（像晝夜 tint 呼應現實時間） | 需說清「哪層是持久、哪層是氛圍」 | **建議採 C** |

**C 的分層說明（關鍵，請 Fable 拍板）**：
- **持久季節（決定相遇卡、日誌、地貌植被狀態）= 綁里程**（A）。確定性、離線可重現、零 FOMO。
- **氛圍季節 tint（純視覺色溫微偏，不入狀態、不記錄）= 可選綁真實日期**。這**完全等同 `03` §1.4 晝夜 tint 綁現實時間的既有做法**——晝夜 tint 讀現實時鐘只是為了「畫面呼應此刻」，從不被結算、從不影響持久內容，所以**不觸犯 `09` §2.1**（該紅線針對的是「用牆鐘決定持久/可回顧的東西」）。
  > 需 Fable 判斷：氛圍季節 tint 要綁「里程季節」還是「現實日期」？綁里程 = 世界內在一致（你走到的季節就是畫面的季節）；綁現實日期 = 與使用者生活同步但可能與「里程季節」打架。**Opus 傾向氛圍 tint 也跟隨里程季節**（世界內在一致最無認知負擔），把「現實日期同步」列為未來可選彩蛋，非核心。

### 3.3 季節如何與地域交織（呼應 `03` §1.4 色溫/晝夜）

- **四季 × 地域 = 各自的 tint 與植被狀態**：春林（嫩綠、花）、夏林（濃綠、蟬）、秋林（金紅、落葉）、冬林（疏枝、薄雪）——這是**組合爆炸**的又一維（§1.3），且**大多可用 tint + 少量素材替換低成本達成**（見 §7 美術策略）。
- **季節推進的呼吸感**（`03` §3.4）：季節過渡與晝夜、地域轉場一樣是**分鐘級/里程級平滑漸變**，任一瞬間察覺不到跳變。
- **三條慢軸交織**：**晝夜（綁現實時間，分鐘級）× 季節（綁里程，很慢）× 地域（綁里程，中慢）**——三條不同週期的慢軸疊加，讓「此刻畫面的樣子」永遠是獨特的組合，卻又每一條都平滑、可預期、無突兀。這是「永遠變化」在**視覺層**最省力的實現。

## 4. 國家 / 城市 / 文化 / 人文

### 4.1 原則：留白的「風味」，不是百科

願望要「穿越各種國家、城市、文化、人文」，但 `02` §5（留白可投射）與 `14`（不淪為百科）要求**克制**。核心分寸：**呈現「風味的印象」，不呈現「設定的資訊」**。

- ❌ 不做：國名/地名的世界觀百科、政治史地、可查詢的文化條目資料庫、對話系統（ADR-006 排除）。
- ✅ 做：**一個聚落遠遠的輪廓、一種屋頂的形狀、一縷炊煙的味道、一場遠處看見的燈火節慶**——用**意象**讓使用者**感覺到**「這裡的人和上一片土地不一樣」，細節由使用者自己填（`02` §5）。

### 4.2 承載方式：聚落地標 + 文化相遇卡（沉默旅人不需對話）

- **聚落地標 (Settlement Landmark)**：某些 `RegionType`（如「河谷村鎮」「海港」「高原聚落」）的地域帶裡，authored 一個聚落地標——旅人**路過**它（不進入、不互動，延續 ADR-009 世界捲動、`03` §3.3 世界變化說話）。它的文化風味靠**造型 + 色調**傳達（`03` §1.2「石門靠造型不靠顏色」的同一原則）。
- **文化相遇卡（`category: 人文`）**：帶地域/文化標籤的相遇卡，記一句留白日誌：
  - 「路過一個小鎮，屋簷下掛著曬乾的紅辣椒。」
  - 「遠遠有燈火，好像在辦什麼節慶。你沒過去，只是看了一會兒。」
  - 「有人在路邊賣熱的東西，香味飄了很遠。」
  - **注意分寸**：全是**旅人視角的一瞥**，沉默、不對話、不解釋這是什麼節、什麼族——**留白讓使用者投射自己去過或嚮往的地方**。
- **「國家」的呈現極度克制**：不給國名。頂多在很長的旅程跨越後，用一句極淡的日誌暗示「這裡的話已經聽不懂了」「路牌換了種字」——**是「走得很遠了」的溫柔實感，不是地緣設定**。是否要做這層，列為 Fable 可選（Opus 傾向「風味印象」足矣，國界感點到為止）。

## 5. 動植物 / 食物（soft-fascination 的相遇內容）

### 5.1 定位：純情感/敘事的 soft fascination，零功利

`02` §6 ART 的 soft fascination 就是「不費力地被自然吸引 → 注意力恢復」。動植物/食物是這一層最直接的載體，**且嚴守 ADR-006 零功利**——看見一隻鹿、路過一種花、嚐到某地的食物，**只給情感與敘事，不給任何資源/加速/解鎖/收集分數**。

### 5.2 承載方式：地域×季節標籤的相遇卡（A 持久 + B 氛圍）

- **B 類氛圍微相遇（純裝飾、不記錄）**：該地域該季節「該有的生命」在畫面裡自然出現——草原有掠過的鳥、林裡有松鼠、海岸有海鳥、花田裡有蝶。純 render 層，錯過毫無損失（連紀錄都沒有，天然守 §7 錯過無損）。這一層**最便宜地製造「世界活著」的臨場感**（`02` §2）。
- **A 類里程相遇卡（入日誌、可回顧）**：偶爾一次更「被看見」的遭遇，記一句留白日誌：
  - **動物**：「一隻鹿在林間抬頭看了看，又低頭吃草。」「一群候鳥從海那邊飛過。」
  - **植物**：「路過一整片開得正好的野花坡。」（＝既有 §10 `wildflower_slope` 的一般化）「秋天的楓葉紅得像要燒起來。」
  - **食物**：「在小鎮嚐到一種沒吃過的熱湯，暖了一路。」「路邊的果子熟了，摘了一顆。」——**食物是「嚐到 / 路過」的情感記憶，不是補給品**（零功利：不回血、不加速、無飽食度）。
- **標籤驅動的在地感**：每張卡的 `tags` 決定它只在對的地域/季節出現——沙漠不會遇到鹿、冬天的花田不會開花。這讓「動植物/食物」**天然承載了地域與季節的差異**，是「永遠變化」最有情感重量的一維。

> **紅線提醒**：動植物/食物**絕不做成圖鑑/收集冊**（「已收集 23/100 種動物」＝踩收集強迫，見 §6）。它們是**路過的風景與心情**，看過就好，日誌裡回味得到，但**沒有「蒐集完整度」這回事**。

## 6. 無終點如何守心理學紅線（本文件的良心）

### 6.1 核心命題：無邊 ≠ 無盡刷

無終點世界最大的心理風險，是被（工程直覺或遊戲慣性）實作成「**永遠有做不完的事**」。必須在設計層**明確劃掉**以下每一項——它們是無邊內容最容易反射性長出來的壓力源：

| ❌ 絕不做（無邊世界的壓力源） | 為什麼危險 | ✅ 改為 |
|---|---|---|
| **完成度 / 收集度 %** | 只要有分母，就有「還差多少」的焦慮；無邊世界分母無限 → 永遠差很多 | **沒有分母**。旅程只有「走過的」，沒有「總共有多少」 |
| **「未探索區域」提示 / 地圖迷霧** | 製造「有地方我還沒去」的驅使感（FOMO 的空間版） | **前方永遠是留白的**，不預告、不列清單、不畫「還沒去的點」 |
| **圖鑑 / 收集冊 / 地域徽章** | 把「路過的風景」變成「要蒐集的物品」→ grind | 日誌是**回憶**（走過什麼），不是**清單**（該蒐集什麼） |
| **每日 / 限時 / 季節限定** | 直接踩紅線一、二（懲罰離開 + FOMO） | 一切綁里程、確定性；同一段路何時走到都一樣（`09` §2.1） |
| **「N 周目」/ 重置 / 里程重來** | 遊戲成就語言，偷渡成就驅力（`14` §2.3） | `distance` 只增不減、永不重置（紅線一） |
| **稀有度 / 稀有相遇卡** | 變動比率增強的本體（`02` §7） | 所有相遇卡地位平等，都只是「路過的一段」 |
| **成就 / 里程碑徽章彈窗** | 把陪伴變成打卡 | 章節名（progressive disclosure，`09` §4.3）＝留白意象，非成就播報 |

### 6.2 「無終點」是安心，不是壓力——三個定調

1. **進展只增不減**（紅線一）：走多遠都存著，永不倒退、永不枯萎。離開三個月回來，旅人是「走了更遠 / 在某片風景裡等你」，不是「荒廢」。
2. **錯過無損，因為「還沒走到」**（紅線二）：無邊世界前方永遠有內容，但那不是「你錯過的」——是「你還沒走到的」。路一直都在，慢慢走都會遇到。被 12h cap 截斷不是損失（`09` §2.4）。
3. **停在哪裡都完整**（紅線四/六、SDT 自主）：無終點**不製造「該繼續走」的義務**。使用者可以就停在某片海岸看很久，可以幾週不管它——世界不催、不亮紅點、不推播（紅線三）。**「路還在」是被動的安心，不是主動的召喚。**

> **一句總綱（承 `14` §6）**：無終點世界從頭到尾**沒有一件「你必須走完、否則會怎樣」的事**。它只是一條永遠向前、永遠有新風景的溫柔的路——你可以一直走，可以停下來看很久，也可以放著。**它的無邊讓你安心（路一直都在），而不是讓你有做不完的事。**

### 6.3 逐條對照六條紅線

| 紅線 | 無邊世界的最大誘惑 | 本設計的落地 | ✅ |
|---|---|---|:--:|
| **一：不懲罰離開/缺席** | 「久沒玩，地域荒廢/季節錯過」 | `distance` 只增不減；季節綁里程（你走到哪季就是哪季，不會「錯過春天」）；離線同速（ADR-005） | ✅ |
| **二：無 FOMO** | 限時地域、季節限定卡、稀有相遇 | 全綁里程確定性；無限時、無稀有度；同一段路何時走到都同一批內容；前方是「還沒走到」非「錯過」 | ✅ |
| **三：無負向催促/討拍** | 「新大陸已開放，快來探索！」推播、未探索紅點 | 無推播召回、無紅點、無「新區域解鎖」提示；轉場是環境自己變、不宣告 | ✅ |
| **四：互動邀請非強迫** | 「蒐集動植物需點擊/餵食」 | 相遇卡零操作自動入日誌；動植物/食物純看見、零功利（ADR-006）；無收集任務 | ✅ |
| **五：不看黏著指標** | 用「地域數/收集率」當 KPI | 成功＝「掛著會遇到新風景、被陪著走」，非開啟率/走了幾個地域；無收集率此指標不存在 | ✅ |
| **六：不剝奪安心不看** | 「盯著才會遇到稀有地域/生物」 | 一切里程軸確定性、離線同速；看不看、多常開，世界都以同一步調走同一條路（`09` §2.1） | ✅ |

### 6.4 對照 `02` §7「療癒 vs 剝削」判準表

| `02` §7 面向 | ✅ 本設計（療癒） | ❌ 禁用（剝削） |
|---|---|---|
| 意外驚喜的目的 | 讓永遠的旅程有新鮮風景、值得偶爾一看 | 為了拉高開啟率 / 讓人怕錯過新地域 |
| 獎勵可預期性 | 地域/季節/相遇卡皆里程確定性；同段路恆定 | 隨機刷地域 / 稀有生物掉落 |
| 錯過的後果 | 「還沒走到」，路一直在，離線補算入日誌 | 限時地域 / 季節限定卡永久錯過 |
| 對離開的態度 | 停在哪都完整，鼓勵去過生活 | 用「未探索/未收集」挽留 |
| 成功指標 | 平靜、被陪伴、「走了好遠好美」 | 地域數 / 收集率 / 日活 |

## 7. 與現有的相容 + 分階段路線（含美術瓶頸誠實標註）

### 7.1 與現有機制完全相容

無邊世界**不推翻任何既有工程**，是既有里程軸範式的**自然延伸**：

- **既有「草原/村莊」地域 = Region 0（第一段地域）**。`09` §10 的 5 地標 / 5 里程事件 / 相遇（237600）/ 3 章節**原封不動**成為第一片草原的 authored 內容——**不浪費、不改寫**（延續 `14` 對 §10 定案的尊重）。
- **地域序列、季節、相遇卡挑選**全部是 `distance` 的**純函式**，與 `SimulationRules.landmarks/events(crossedFrom:to:)`、`OfflineProgress.settle` 的既有確定性範式同構（`09` §6）——**線上/離線同一套判定，離線可重現的迴歸鎖不變**。
- **tint / 天氣**複用 `03` §1.4 既有全域 tint 機制；**parallax 圖層**複用 `03` §2.4 既有 L0–L7 結構，只是**換素材集**。

### 7.2 美術是主要瓶頸（誠實標註）

> **這是本規劃最大的成本與不確定，必須誠實講清楚。**

- **程序化的東西幾乎零成本**：地域序列、季節週期、相遇卡挑選、tint 漸變——都是純邏輯 / tint 插值，**加一種地域類型的「邏輯」不花錢**。
- **貴的是每個新地域/季節的「素材」**：每個新 `RegionType` 需要新的 parallax 地貌素材集（近景圖磚、中景丘陵/樹線、遠景山形、聚落造型）；每個季節理想上要植被狀態變體。**目前美術只有一個「草原/村莊」地域的素材表**（使用者用 ChatGPT 生的）。
- **兩個成本分級**（善用便宜的那層）：
  - **便宜（優先榨取）**：**tint / 色溫 / 天氣權重 / 相遇卡文字**——換色調就能讓「同一片林」有春夏秋冬四種氣氛；加相遇卡只是寫字。**低成本就能把「現有素材」的變化感大幅拉高。**
  - **貴（分階段擴充）**：**全新地貌素材集**（新地域的樹、山、聚落造型）。這需要使用者用 ChatGPT 逐地域生新素材表，是長期、漸進的工作。
- **不確定性**：ChatGPT 生成的像素素材能否在**風格一致性**（同一調色盤、同一像素規格 `03` §2）、**parallax 分層可用性**上穩定產出，需實作驗證。**「一個地域一套風格一致的多層素材」是這條路線最大的未知數。**

### 7.3 建議分階段路線

> 原則：**先用便宜的層把「現有素材」的變化感做滿，再逐地域擴充貴的素材。** 每階段都可獨立驗收、都不踩紅線。

| 階段 | 內容 | 美術成本 | 產出的體驗 |
|---|---|---|---|
| **Stage A：地域系統骨架 + 季節 + 更豐富相遇卡（於現有草原素材上）** | ① 把 Region/Season 抽象成里程純函式（Region 0 = 現有草原）；② 季節 tint 週期（春夏秋冬四套 tint，套在現有草原素材）；③ 大量擴充相遇卡池（動植物/食物/人文，帶地域×季節標籤）；④ 相遇卡確定性挑選 | **極低**（只加 tint 與文字，複用現有素材） | 「同一片草原，四季不同、每次走都遇到不一樣的溫柔小事」——**光這一步就大幅兌現「永遠變化」**，且零新素材依賴 |
| **Stage B：第二個地域類型（如森林）** | 用 ChatGPT 生一套風格一致的「森林」parallax 素材表；接上地域序列（草原→疏林→森林的 Blend Zone）；驗證「新素材風格一致 + 分層可用」的流程 | **中**（一套新地貌素材 + 驗證流程） | 「走著走著，草原變成了森林」——**第一次真正的地域轉場**；跑通「加一個地域」的完整流程 |
| **Stage C：逐地域滾動擴充** | 每次加一種 `RegionType`（丘陵/濕地/海岸/沙漠/高山/花田…）+ 其相遇卡；地域序列自動把它們編織進無邊旅程 | **每地域一套素材**（漸進、可長期） | 旅程越來越廣、地形氣候文化越來越多樣；**內容擴充與工程解耦，可持續慢慢加** |
| **Stage D（可選）：聚落/文化/國界感 深化** | 聚落地標造型、文化相遇卡深化、極克制的「走到很遠了」國界感暗示（§4.2） | 中（聚落造型素材 + 文案） | 人文風味的層次；「穿越國家/城市/文化」的兌現 |

> **Stage A 是最高 CP 值的一步**：它**不依賴任何新美術**，卻能把「永遠變化」從無到有兌現一大半（季節 × 擴充相遇卡的組合爆炸）。建議**優先做**，作為無邊世界的最小可行版本，也讓後續每個新地域都「加進來就自動變豐富」。

| 檢查項 | 依據 | 本文件的落地 | ✅ |
|---|---|---|:--:|
| 無黑暗勢力 / 反派 / 威脅 | `14` + `02` §6 | 世界觀層級即不存在；無邊只是「更多美好的地方」，不含任何危險地域 / 敵對文化 | ✅ |
| 不懲罰離開 / 缺席 | 紅線一 | `distance` 只增不減、永不重置；季節綁里程（不會「錯過季節」）；離線同速（ADR-005） | ✅ |
| 無 FOMO | 紅線二 | 無限時 / 限定 / 稀有；地域/季節/相遇卡全里程確定性；前方是「還沒走到」非「錯過」 | ✅ |

| 不剝奪安心不看 | 紅線六 | 一切里程軸確定性、離線同速；世界以自己步調走同一條路，與看不看無關 | ✅ |
| 純情感 / 敘事、零功利 | ADR-006 | 相遇卡 / 地域 / 季節 / 動植物 / 食物 / 文化只給情感與敘事，不給資源/加速/解鎖/收集分 | ✅ |

## 9. 給 Fable 的定案摘要

**世界結構模型**：以**地域帶 (Region Band)** 為單位沿里程軸串接，前進＝走進新地域（延續「遇到＝走到了」哲學）。地域間用**漸變重疊帶 (Blend Zone)** 平滑轉場（tint 插值 + 地貌交融，複用晝夜漸變機制）。**無限延伸靠「少量 authored 地域類型 + 確定性序列生成」**（`bandIndex` 的純函式，帶連貫性約束），**不重複到膩靠組合爆炸**（RegionType × Season × 晝夜 × 天氣 × 相遇卡）。石門/雪山降格為某地域類型裡的一個地標（呼應 `14`）。

**authored + 程序化策略**：**authored 建構塊（地域類型、季節、相遇卡）+ 確定性程序化組合（里程/seed 純函式，絕不牆鐘）**。內容最小單位是**相遇卡 (Encounter Card)**＝一句留白日誌 + 地域/季節標籤 + 分類（風景/動物/植物/食物/人文…），零功利欄位。**新增內容 = 多寫幾張卡，程序化層不用改（內容擴充與工程解耦）**。變化來自「走過的里程」而非「使用者操作」，故天然不 grindy、錯過無損、無 FOMO。

**季節/氣候**：**氣候綁地域**（沙漠乾熱、海岸濕潤）；**季節綁里程**（`season = f(distance)` 慢週期，確定性可重現，是「旅程即人生」的時節而非日曆）。建議**混合方案 C**：持久層（相遇卡/日誌/植被）綁里程，純氛圍 tint 可選層——Opus 傾向氛圍也跟里程季節（世界內在一致）。三條慢軸（晝夜綁現實時間 × 季節綁里程 × 地域綁里程）交織出永遠獨特卻平滑的畫面。

**文化/動植物/食物怎麼承載**：**聚落地標（路過、不進入）+ 文化/動植物/食物相遇卡**，沉默旅人不需對話。全是**旅人視角的一瞥、留白的風味印象**（不是百科、不是圖鑑、不給國名設定）。動植物/食物是 soft fascination 的情感相遇，**零功利、無收集冊**。

**無終點如何守紅線**：無邊 ≠ 無盡刷。**明確劃掉**完成度%、未探索提示/地圖迷霧、圖鑑收集冊、每日限時、周目重置、稀有度。無終點是**「路一直都在」的安心**（進展只增、錯過是「還沒走到」、停在哪都完整），不是「永遠做不完」的壓力。六條紅線 + `02` §7 判準表逐條對照通過（§6、§8）。

**分階段路線與美術瓶頸**：**美術是主要瓶頸**——程序化幾乎零成本，但每個新地域/季節要新素材，目前只有一個草原素材表。策略：**先榨取便宜的層（tint/季節/相遇卡文字），再逐地域擴充貴的素材**。
- **Stage A（最高 CP，不依賴新美術）**：地域系統骨架 + 季節 tint 四套 + 大量擴充相遇卡，全套在現有草原素材上 → 光這步就兌現「永遠變化」一大半。
- **Stage B**：第二地域（森林），跑通「ChatGPT 生風格一致多層素材」的流程（此為最大未知數）。
- **Stage C/D**：逐地域滾動擴充 + 聚落/文化深化。

**最需 Fable 拍板處**：
1. **季節綁定方案（§3.2）**：確認採混合 C（持久綁里程 + 氛圍 tint 可選）？氛圍 tint 跟「里程季節」還是「現實日期」？（Opus 傾向跟里程季節，世界內在一致。）
2. **「國界感」要不要做、做多淡（§4.2）**：Opus 傾向「風味印象」足矣、國界感點到為止、不給國名。
3. **地域類型清單與相遇卡的語氣/內容**：authoring 權在 Fable（同 `09` §10）；本文件只給結構與意象方向，不寫定稿文案。
4. **Region/Season 的里程尺度**（`regionLength` / `seasonLength`）：相對 P1 速率、待手感定（同 `09` 待驗收參數精神）——一帶多長、一季多少里程，牽涉「多久換一次風景」的節奏手感。
5. **確認優先做 Stage A**（不依賴新美術、最快兌現願望）作為無邊世界的最小可行版本。

> 本文件只寫世界結構模型與內容策略，**不碰程式碼、不改任何已定案內容**。所有機制皆為既有里程軸確定性範式的延伸，與 `09` §2/§6、ADR-005 完全相容。美術成本與 ChatGPT 素材風格一致性為誠實標註的主要不確定。
