# 陪伴感設計 — 非侵入的桌面陪伴（Ambient Companionship）

> 準則一（心理學為本）核心文件。承 `02_PSYCHOLOGY_FOUNDATION`、ADR-002（非侵入）、ADR-006（零功利邀請）、ADR-004（主角獨行→**陪的是使用者**）。

## 0. 一句話定位
**在你螢幕角落獨行的旅人與那個慢慢流轉的小世界，是「你」使用電腦時的安靜同伴——透過「在場、覺察你、共享此刻」讓你感到被陪伴，而不是透過「活動、要求你注意」來刷存在。**

## 1. 要解的張力（本設計的全部重點）
| | 社會臨場（陪伴感） | Calm Technology（非侵入） |
|---|---|---|
| 想要 | 感覺有人在、被覺察、一起 | 不搶注意力、不打斷工作、可退到餘光 |
| 天然衝突 | 通常靠「動作/互動」建立 | 動作/互動正是打擾來源 |

**解法核心洞見**：**陪伴感來自「可得性 availability + 覺察 awareness + 共存 shared existence」，不是來自「活動 activity + 要求 demand」。**
— 一隻趴在你桌上安靜睡覺的貓，不做任何事，卻讓整個房間有人陪。牠靠的是「在場 + 偶爾抬眼看你 + 跟你共處同一個下午」。這正是我們要做的：**安靜的在場者**，不是表演者。

## 2. 心理學六柱（每條＝一個可實作的陪伴來源）
1. **社會臨場・被看見（social presence / being witnessed）**：偶爾看向你 → 你感到「有人覺察到我在」。§2。
2. **Calm Technology・餘光在場（peripheral presence, Weiser & Brown）**：資訊/存在活在注意力邊緣，需要時才進中心。陪伴訊號必須是低顯著度、可被餘光接收、不強拉焦點。
3. **共時共存（synchronized existence）**：牠活在你的真實時間裡——晝夜、季節、天氣同步 → 「此刻我們在同一個世界」。已部分實作，可深化。
4. **安全堡壘・可得不強求（secure base / availability, attachment theory）**：可靠地一直在、你回來牠還在；只在你「邀請」（看牠/靠近/點）時給溫暖。ADR-006。
5. **注意力恢復・柔和魅力（ART soft fascination, Kaplan）**：牠的小世界是「一扇通往寧靜的小窗」，你需要微休息時瞥一眼即恢復（像望向真的窗外）——把桌寵定位為**恢復性**而非分心。§6。
6. **關係性共同歷史（relational shared history）**：累積的不是成就，是「一起」——一起走過秋天、一起看過很多次日落。溫柔、無壓力、無數字競賽。

## 3. 非侵入憲章（紅線，任何陪伴機制都不得違反）
1. **絕不打斷**：永不出聲、不彈窗、不用會不自主抓住眼睛的動作/閃爍。所有「在場脈動」必須慢、小、在餘光。
2. **拉不推（pull, not push）**：桌寵是「可得的」，你來找它；它永不主動要求你注意。
3. **低喚醒**（§6）：慢動作、柔和色、克制。你在專注工作時，它只是在那裡呼吸、偶爾抬眼——永不升級。
4. **隱私・絕不窺視你的工作**：陪伴感只能來自**良性訊號**——真實時間、你的明確互動（hover/點/回來）、OS 層的閒置/活動（無內容）、共享的小世界。**絕不讀取視窗標題、鍵盤、你在做什麼**。窺視＝最大的侵入與背叛。
5. **可退場**：reduce-motion / 專注模式下更靜；使用者永遠能調弱或請它安靜。
6. **零功利**（ADR-006）：陪伴不綁生產力、不記錄你多勤勞、不製造愧疚。

## 4. 分階段路線圖（每階：心理學根據 → 機制 → 非侵入保險 → 文件 → 施工 → 驗收）

### Stage P1 — 在場與歸來（Presence & Return）★ 先做
- **P1a 歸來的溫暖**：你離開後回來（螢幕解鎖 / 應用重新聚焦 / 長閒置→活動），旅人給一個**低調的「你回來了」微反應**（停步、看向你一下、極輕的暖光）。心理：重逢 reunion（依附）+ 被看見。保險：一次性、低顯著、有冷卻、絕不出聲。
- **P1b 仍在身邊**：長時間連續工作中，**極稀疏**地（如每 20~40 分、變動間隔）做一個餘光可見的生活訊號（伸展/看向遠方一隻鳥/坐下歇一會）——提醒「有人在」而不奪焦。心理：純在場效應 / 社會緩衝。保險：頻率上限、變動、活動劇烈時不做、純餘光。
- **P1c 陪你休息**：偵測到你一段時間沒動（OS 閒置，無內容窺視），旅人也**坐下來歇著**，跟你一起靜下來。心理：靜止中的共存 co-presence。你一動，它自然起身繼續。

### Stage P2 — 共時的深化（Shared Moment）
- 晝夜/季節/天氣同步之上，加「**與你同步的一天**」的氛圍：傍晚牠也慢下來、清晨稍微醒神；深夜工作時牠的世界也是靜夜（可選「你還沒睡，我陪你」的極輕存在）。
- **關係性時間刻度**（一起，非成就）：「我們一起走過了一個秋天」「又一起看了場雨」——當作超輕的旅程日誌，關係語氣。

### Stage P3 — 靜定的錨（Calm Anchor / 恢復）
- 打磨呼吸/歇息節奏，讓「瞥一眼」真的安神（ART）。桌寵＝角落一扇會呼吸的小窗，你可以隨時望向它微休息——純 pull、無提示。
- （可選）與 P1c 呼應的「一起靜下來」深化。

#### P3 施工細節 — 休息呼吸共調（rest-breath co-regulation）
- **心理學**：coherent breathing / HRV 共振研究指出 ~6 次/分（一次呼吸 ~10 秒）的緩慢呼吸能降交感喚醒。旅人**走路時**用一般呼吸（現行 3.6s 週期），**歇息時**（`isCharacterResting`/`isAwayResting`——偶爾看你、陪你歇）切換成**更慢的休息呼吸（~10s 週期）**。使用者餘光瞥見歇著的旅人緩慢起伏，成為一個可自願跟隨的呼吸節拍器（entrainment）→ 幫你也靜下來。ART 柔和魅力 + 生理共調。
- **機制**：`CharacterNode` 加「休息呼吸」模式——rest 開始時把 breathing loop 換成慢版（週期 ~10s、振幅可略增到仍克制的程度讓 10s 下仍可察覺「活著」但不刺眼，如 0.018~0.022），easeInEaseOut；rest 結束回走路呼吸（3.6s）。呼吸切換本身要柔和過渡、不跳。
- **非侵入/保險**：純視覺、無提示、無聲、pull 不 push（你不看也無妨）；reduce-motion 下呼吸 loop 一律移除（沿用現行，位移/縮放類）；低喚醒（§6）——慢呼吸不能變成明顯脈動。
- **需使用者實測的是「感覺」**：是否真的安神、10s 下是否仍看得出在呼吸而非靜止——由使用者 live 回饋定調振幅/週期。Fable 雙鏡把關 craft（過渡 easing、振幅克制、不 jolt）與心理學（低喚醒、非侵入、pull）。

### Stage P4 — 尊重專注的分寸（Focus-aware，隱私安全）
- **專注/安靜模式**（手動優先，或極粗略自動）：你明顯埋頭時，桌寵更靜（動作降到最低）＝純寧靜在場；你放鬆瀏覽時，稍微活一點。心理：Calm Tech「需要專注時退開、不需要時輕輕在」。
- **鐵律**：只用**粗略、隱私安全**的訊號（使用者設定的模式 / 時間 / OS 閒置-活動），**絕不讀取工作內容**。寧可笨一點，不可窺視。

#### P4 施工細節 — 專注時退場（focus-aware quieting）
- **心理學**：Calm Technology 的核心是「需要專注時退到餘光、不需要時才輕輕在」。一個好同伴知道你忙時要安靜。
- **偵測（隱私安全）**：只用 OS 閒置秒數（`CGEventSource`,無內容,同 P1）。**持續活動**（閒置一直很低）累積超過門檻（如連續活動 > 4~5 分鐘）→ 判定「專注/心流中」；一旦出現一段短閒置（如 > 20~30 秒的停手/微休息）→ 退出專注。純函式 `FocusState`（依閒置樣本判斷）可測。**絕不看你在做什麼、不量化你多勤勞**（只有「還在動 / 停手了」的二元粗訊號）。
- **專注時的行為（純減法＝天然非侵入）**：
  - **暫停所有會彈出的 toast**（相遇卡、關係句、深夜句都不冒——深深專注時連溫柔的字都不該打斷你）。
  - **收起「偶爾看你」**（那是唯一會微拉注意力的角色行為）。
  - 只剩：角落安靜走路 + 呼吸。純寧靜背景在場。
- **休息時恢復**：一出現短閒置（你停手喝口水/看向別處）→ 退出專注 → 世界輕輕恢復生氣（toast、看你回來）。歸來的溫暖（P1a）本就發生在「回來」時、不受此影響。
- **與 P1c 分層**：短閒置(退專注,世界恢復) < …活動… > 長閒置 180s(陪你歇)。三態自然銜接。
- **非侵入/隱私**：本階全是**減法**（更少彈出、更少拉注意）＝結構上不可能更打擾;只用閒置二元訊號、零窺視。Fable 雙鏡把關（心理學:確認是「退場」不是新打擾;design-eng:狀態切換無突兀、toast 暫停/恢復乾淨不掉幀）。

## 5. 先做 P1、怎麼驗
P1 是最貼題、最高情感投報的起點（「歸來被迎接 + 仍在身邊 + 陪你歇」直擊「有人陪你」）。全部用既有良性訊號（app 聚焦/失焦、OS 閒置時間、既有 look-at-you/rest 微行為），不新增任何窺視。
- 施工：延伸既有 `HeroRestSchedule`/`ProximityAwareness`/微行為，加「歸來偵測」（app 重新 active / 長閒置後首次活動）與「陪你歇」（閒置→旅人 rest）。
- 驗收：Fable 截圖 + 使用者實測「回到電腦時被輕輕迎接、埋頭時它安靜陪著、久沒動它也歇下來」的感覺；且**確認完全不打擾**（無聲、無彈窗、餘光級）。

## 5b. Stage P2 施工細節（共時的深化）— Fable authored

### 機制
- **與你同步的一天（time-of-day 陪伴）**：用**真實時間**（良性訊號，既有 DayNightCycle 已有）。深夜工作時（真實時刻 23:00–04:00），旅人**極稀疏**地做一個「夜裡我也還在」的低調存在（看向你 + 偶爾一句深夜陪伴日誌）。純在場、**絕不勸你睡**（不是提醒 app，是陪伴）。低喚醒、有長冷卻、無聲。
- **關係性時刻（relational milestones）**：沿累積里程（＝一起走過的時間，`gameState.distance` 為代理）每隔一大段（稀疏、確定性）冒一句**「我們一起」**的旅程日誌——關係語氣、無數字、無成就、無圖鑑（守紅線）。與相遇卡（寫景）區隔：這類是寫「我們的關係」。
- 呈現：沿用既有 journey-log toast、錯開、克制；受 motionEnabled 控制。

### Authored 內容（語氣：溫暖、留白、關係性、反把「你」當成陪伴我的人）
**關係性時刻（隨里程稀疏出現）**
- 「不知不覺，我們一起走了好長一段路。」
- 「又一起走過了一個季節。」
- 「一起看過的日落，已經數不清了。」
- 「路還長，還好有你在。」
- 「有些風景，是因為有人一起看著，才留得住。」
- 「你在的時候，連沉默都覺得踏實。」

**深夜陪伴（真實時刻深夜，稀疏、純在場、絕不勸睡）**
- 「夜深了。你還在，我也還在。」
- 「夜裡很安靜，我陪你走一段。」
- 「燈還亮著。不急，我在。」
- 「這麼晚了還在忙。我不吵你，就在這。」

**（選）破曉（真實清晨 5–7 時，罕見）**
- 「天要亮了。這一夜，有你，不孤單。」

### 非侵入保險
稀疏（深夜/關係各有長冷卻）、低喚醒、無聲、無彈窗、餘光級；深夜語氣嚴禁變成健康提醒/說教（那是侵入）。

## 6. 不做（避免踩非侵入/隱私）
讀取你在做什麼、依你的工作內容反應、彈出提醒/建議、發出聲音、量化你的勤勞、任何「該互動」的推力、**任何「該去睡/該休息」的健康說教**。
