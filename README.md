# Find Your Way

一款 **macOS 原生桌寵式懸浮陪伴軟體**：中世紀奇幻像素風、2D 橫向捲軸放置類冒險。
一個旅人在螢幕角落的透明懸浮視窗中自主前行、翻山越嶺、穿過村落與天空之城 —— 靈感來自吉卜力風格的翻山旅途。

> **核心情感目標：「有人陪你走人生這場冒險。」**
> 追求在你使用電腦時**低負擔的陪伴感與療癒感**，而不是遊戲的征服感 —— 陪著你，但**絕不打擾你正在做的事**。

## 這是什麼

- **一位獨行旅人**，在透明無邊框的懸浮視窗裡原地行走（世界向後捲動表現「前進」），走過 **13 個手繪像素地域**組成的無盡循環：
  農村 → 樹屋村 → 城堡首都 → 溫泉山村 → 海港 → 雪山王國 → 蒸氣龐克飛船城 → 賽博龐克霓虹夜城 → 浮空平台村 → 仙俠山宮 → 浮空魔法城 → 聖光之城 → 天空城 → （回到農村）。
- **真多層視差**：每個地域由遠景／中景／前景／地面四層獨立圖層疊出景深，隨里程無縫平鋪捲動。
- **會呼吸的世界**：晝夜光影、四季色調、天氣（晴／陰／雨）全部**依里程確定性演算**（不靠時鐘亂數）—— 同一段旅程永遠得到同一片風景。
- **可拖曳、可縮放**：拖視窗任意處移動、拖右下角拉手縮放場景（拉寬看更廣的世界），位置與尺寸都會記住。

## 陪伴設計（本專案的靈魂）

陪伴感來自**可得性 × 覺察 × 共存**，不是活動與要求 —— 像一隻睡在你腳邊的貓。全部機制都有心理學依據（見 `docs/22_COMPANIONSHIP_DESIGN.md`）：

- **在場與歸來**：你回到電腦前（螢幕喚醒 / 久違的活動）時，旅人以一點暖光與起身回應你的歸來。
- **陪你歇**：你久未操作時，旅人停下腳步，在原地以側視待機動畫「活著地歇著」（呼吸、偶爾一片落葉），而非凍結。
- **共存呼吸**：休息時切換到約 10 秒一循環的慢呼吸，成為餘光可自願跟隨的呼吸節拍器（coherent breathing / HRV 共振）。
- **不打擾的覺察**：偵測到你正專注時，自動收起所有訊息與「看你」的動作，退到最安靜的存在。

### 非侵入憲章（紅線，永不打破）

- **絕不**打斷你、**絕無**聲音、**絕無**彈窗；一切訊息是「拉」不是「推」（要看才看得到）。
- **絕不窺視你在做什麼** —— 只讀取系統的「距上次操作幾秒」（`CGEventSource` 閒置秒數），**不讀**視窗標題、App 名稱、鍵盤內容、螢幕內容。
- **不說教**：不勸你睡覺、不管你健康、不量化施壓。
- **零功利**（ADR-006）：點旅人只有純情感回應，**不給**任何資源／加速／解鎖 —— 陪伴本身就是目的。

## 設計準則（不可打破）

1. **心理學為本** — 任何機制／設計都要有心理學、色彩學、UI/UX 理論依據。
2. **先文字後實作** — 一切先寫進 `docs/`，確保任何協作 session 中斷都能無縫接手。
3. **分層協作省 token** — 規劃／review 與實作分工。

## 隱私

這是一個**在你工作時陪著你**的常駐軟體，因此隱私是設計的第一原則：它**只**知道「你多久沒動滑鼠鍵盤了」，用來決定要不要讓旅人停下來歇息。它**不知道也不想知道**你在哪個 App、開什麼視窗、打什麼字。無網路連線、無遙測、無帳號。

## 技術棧

- **Swift 5.9 / SpriteKit / AppKit**，SPM 專案，**零第三方依賴**（純 stdlib + 系統框架）。
- 最低 **macOS 13**。透明無邊框置頂懸浮視窗（`.borderless` + `.clear` + `.floating` + 可跨全 Space）。
- **邏輯與 UI 分層**：`FindYourWayCore`（headless 純邏輯庫，可在無畫面環境測試）+ `FindYourWay`（單薄 AppKit/SpriteKit 外殼）。
- **像素美術管線**：`scripts/slice_assets.py` 為**純標準庫**的 PNG 切圖工具（自寫 decode/encode，無 PIL）—— 洋紅（`#FF00FF`）色鍵去背 + 去邊 + 邊緣羽化無縫 + 四邊反距離內插補洞。
- **測試紀律**：純邏輯層 headless 測試，目前 **344 tests 全綠**；每次產出經「心理學 × design-engineer」雙鏡檢視。

## 開發

```bash
swift build      # 建置
swift test       # 執行測試（純邏輯層，headless，全綠）
swift run        # 直接啟動桌寵（Ctrl-C 結束）

bash scripts/build_app.sh && open FindYourWay.app   # 打包成 .app 並執行
```

**操作**：拖視窗任意處＝移動；拖**右下角**＝縮放場景；點旅人＝一次溫柔的「注意到你了」小回應。

### QA 環境變數（截圖／驗收用）

```bash
FYW_DEBUG_REGION=<地域資源夾名>   # 強制指定起始地域（如 meadow_village / harbor / holy_city）
FYW_DEBUG_SEASON=<spring|summer|autumn|winter>
FYW_DEBUG_SECONDS_INTO_DAY=<秒數>  # 模擬一天中的時刻
FYW_DEBUG_WEATHER=<晴|陰|雨>
```
